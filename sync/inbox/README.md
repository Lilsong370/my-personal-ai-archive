# 收件箱

这里是「原料区」，不是成品区。

- 从任何 AI 得到的有价值内容，先丢进 `YYYY-MM-DD.md`（用 `sync/capture.ps1` 自动完成）。
- 文件按天聚合，每条带时间戳和来源标签（chatgpt / claude / gemini / cursor…）。
- 每周复盘时，把这里的碎片提炼进 `01`–`05` 正式模块，然后删掉已提炼的条目。

## 约定

```markdown
## 14:32 [claude]

（原始内容，保持原样，不要提前整理）
```

保留原始表述很重要——整理会丢信息，而你永远不知道哪条细节三个月后会有用。

## 不要放在这里

- 密码、Token、密钥
- 客户名单、合同条款、身份证件
- 公司内部系统地址

这些内容即使仓库是 private 也不建议放进 Git 历史（删不掉）。
