# 对话记录归档

这里存「我和 AI 聊出来的东西」——不是档案，是原料。

## 目录规则

```text
journal/2026-10/2026-10-26.md
```

按月分文件夹，按天分文件。一天里所有 AI 对话按时间顺序往下追加，每条带工具标签和主题。

## 为什么按天

1. 找东西靠时间，比靠标题可靠。
2. 一天一个文件，不会变成几千个碎文件。
3. Git 历史清晰：哪天写了什么，一条 commit 就能看全。

## 一条记录长什么样

```markdown
## 14:32 · chatgpt · 客诉回复话术

（正文，尽量保留原始输出，不要提前精修）
```

## 什么时候回头整理

每周五 10 分钟，把这一周的记录扫一遍，值得留的提炼进 `03-experience.md` 或 `04-learning.md`，然后不用删——原料留着，成品另外存。

## 不要放在这里

- 客户手机号、身份证、地址
- 门店内部群截图里的员工信息
- 任何密码、Token

Git 历史删不干净，放进去就等于公开。
